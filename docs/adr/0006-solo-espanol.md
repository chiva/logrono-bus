# 0006. Interfaz y documentación solo en español

**Estado:** aceptada (2026-10-03)

El público es local. Interfaz, guía y mensajes de error en español; el código y sus comentarios en
inglés, como el resto de proyectos del autor. Excepción: la integración de Home Assistant incluye
`translations/en.json` (copia del español) porque Home Assistant recurre al inglés si falta el
idioma del usuario.
