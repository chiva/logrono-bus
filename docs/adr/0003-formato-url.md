# 0003. El panel se describe en la URL

**Estado:** aceptada (2026-10-03)

Formato `p` versionado (`v=1`): `101-2d.5a~100-2a`. Solo caracteres no reservados de RFC 3986
(sin escapes), corto para teclearlo en un Echo Show y apto para QR. Los parámetros de presentación
se omiten cuando valen lo predeterminado. Un enlace de una versión más nueva da un aviso en vez de
fallar en silencio. Gramática en `logrono_bus/board.py`.
