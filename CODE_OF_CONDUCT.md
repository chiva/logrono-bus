# Código de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
En resumen: trato respetuoso, críticas al código y no a las personas, y cero tolerancia con el
acoso. Para informar de un problema, escribe un
[aviso privado](https://github.com/chiva/logrono-bus/security/advisories/new) indicando que es de
conducta.
